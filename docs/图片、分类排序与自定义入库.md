# 图片、分类排序与自定义入库

## 本地商品图片

从立创商城添加物料时，系统会读取商品主图并下载到：

```text
data/images/C编号.图片格式
```

数据库保存本地图片地址。即使立创商品图片地址以后发生变化，已经下载的图片仍能显示。图片下载失败不会阻止物料和库存入库，系统会暂时保留商品页提供的远程图片地址。

## 调整分类顺序

1. 打开“系统设置”。
2. 找到“分类显示顺序”。
3. 选择要调整的父分类，例如“电子元器件”或“电源管理”。
4. 点击子分类右侧的 `↑`、`↓`。

自定义顺序会保存在数据库中。以后再次同步立创分类时，分类名称和新增分类会更新，但已经设置的显示顺序会保留。

## 扩展的两个按钮

立创商品详情页右侧显示：

- “加入我的物料库”：使用系统默认数量、默认仓位直接入库。
- “自定义加入”：打开参数窗口后再入库。

“自定义加入”可以设置：

- 入库数量
- 入库仓位
- 最低库存
- 单位
- 入库备注

修改过扩展源码后，需要打开 `edge://extensions/` 或 `chrome://extensions/`，在扩展卡片上点击一次“重新加载”，然后刷新已经打开的立创商品页。
