# 图片拖动与流水删除

## 放大图片后拖动

点击物料缩略图或详情图片打开大图，然后：

- 使用鼠标滚轮或 `＋`、`−` 按钮调整缩放；
- 图片大于 100% 时，按住鼠标左键并移动即可拖动画面；
- 双击图片可在 100% 和 200% 之间切换；
- 点击百分比按钮或按数字键 `0` 可恢复 100% 并回到中心；
- 按 `Esc` 或点击关闭按钮退出。

## 删除流水

流水管理窗口现在包含：

- 每条流水右侧的“删除”按钮；
- 顶部的“全部删除”按钮。

在物料详情打开管理窗口时，“全部删除”只作用于当前物料；从库存流水页面打开时，“全部删除”作用于全部物料。

删除后的流水不会再出现在普通流水或管理窗口中，也不能从界面恢复。为防止误删入库记录造成库存突然变化，删除只移除流水显示，当前库存保持不变。数据库内部仍保留最小账本数据用于库存计算和数据完整性。
