# 流水管理、商品描述与自动刷新

## 最近流水备注

物料详情中的“最近流水”会显示每条流水的备注。库存流水页面也会显示备注列，长备注可将鼠标停留在内容上查看。

## 清空流水

“清空流水”采用归档方式，不会删除库存账本，也不会改变当前库存：

- 物料详情中的“清空流水”只隐藏当前物料的流水。
- 库存流水管理窗口中的“清空全部显示流水”隐藏所有当前可见流水。
- 已隐藏流水仍可在“管理流水”窗口中找到并恢复显示。

## 管理流水

物料详情和库存流水页面均提供“管理流水”按钮。管理窗口支持：

- 修改并保存流水备注；
- 隐藏单条流水；
- 恢复已隐藏流水；
- 清空当前物料或全部显示流水。

流水数量不能在管理窗口直接修改，避免绕过库存校验。需要更改库存时，请使用物料详情中的入库、出库或调整操作。

## 商品描述

从立创商城导入时会保存商品页提供的描述，并在物料详情的“商品描述”区域完整展示。手动添加物料时也可以填写描述。

## 自动刷新

物料网页每 750 毫秒检查一次本地数据版本。通过浏览器扩展加入或再次入库后，物料列表、统计数字、库存流水和已打开的物料详情会自动更新，无需点击刷新按钮。
