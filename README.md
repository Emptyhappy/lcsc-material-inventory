# 立创商城物料管理系统

一个运行在本机的电子元器件库存系统。浏览器扩展可以在立创商城商品详情页一键读取商品参数和分类，并按默认数量 `1`、默认仓位直接入库；其他来源的物料可以在系统中手动添加。

## 已实现功能

- 立创商品页一键添加，无需手动填写型号、封装和参数
- 自动读取 C 编号、制造商型号、品牌、封装、规格参数、图片、数据手册、价格和分类
- 重复 C 编号不会重复建档，再次点击会继续入库 `+1`
- 请求防重和刚添加流水撤销
- 扩展“自定义加入”可设置数量、仓位、最低库存、入库备注和元器件备注，并可直接新建仓位
- 严格按立创商城页面顺序同步分类（一级首项为“电容”），支持分类筛选、统计、手动调序和恢复立创顺序
- 手动添加非立创物料
- 手动物料可上传本地图片，非立创来源物料可修改名称、型号、品牌、封装、分类、描述和元器件备注
- 所有物料都可单独修改元器件备注；空备注统一显示“无”，多行输入框会随内容自动增高
- 物料列表支持单个删除和批量管理/批量删除，删除前自动生成安全备份
- 入库备注与元器件长期备注分开保存
- 默认数量、默认仓位和自定义仓位
- 入库、出库、库存调整及完整流水
- 名称、型号、内部编号和 C 编号搜索
- 低库存筛选、CSV 导出，以及包含数据库和本地图片的完整备份导出、完整恢复与“保留现有数据”的备份合并
- 自动安全备份支持高/中/低三级策略，安全备份和正常备份均可自定义保存地址
- 不依赖第三方 Python 包

## 启动物料系统

双击 [start.bat](start.bat)，浏览器会自动打开：

```text
http://127.0.0.1:8765
```

第一次启动会在后台同步立创公开分类。如果当时网络不可用，可以进入“系统设置”，点击“同步立创分类”重试。

数据库默认保存在：

```text
data/materials.db
```

在“系统设置 → 完整数据备份”中可以下载 ZIP，也可以点击“保存正常备份”直接写入设置的正常备份地址。备份包含物料、库存、全部流水、仓位、设置、分类顺序和本地元器件图片。“添加备份中的物料”会保留当前数据并跳过重复物料；“恢复完整备份”会替换当前数据。

自动安全备份有三级：

- 高安全性：删除单个或批量物料、删除单条或批量流水、清空流水、恢复与添加备份前均自动备份。
- 中等安全性：批量删除物料、批量删除或清空流水、恢复与添加备份前自动备份。
- 低安全性：不生成自动安全备份，手动下载和正常备份不受影响。

安全备份默认保存在 `data/backups/safety`，正常备份默认保存在 `data/backups/normal`；两者都可以在页面中改成其他文件夹。

也可以在命令行启动：

```powershell
python run.py
```

## 安装 Edge/Chrome 扩展

### Edge

1. 打开 `edge://extensions/`。
2. 打开左侧“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目中的 `extension` 文件夹。

### Chrome

1. 打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目中的 `extension` 文件夹。

### 首次连接

1. 保持物料系统正在运行。
2. 打开物料系统的“系统设置”。
3. 在“浏览器扩展连接”中复制连接密钥。
4. 打开扩展的“选项/扩展选项”。
5. 粘贴密钥，点击“保存并测试连接”。

连接成功后，打开形如 `https://item.szlcsc.com/100411.html` 的立创商品详情页，右侧会出现“加入我的物料库”按钮。

## 一键添加规则

- 第一次点击：创建物料档案，并在默认仓位入库默认数量。
- 同一个 C 编号再次点击：更新商品信息，不重复建档，继续入库默认数量。
- 同一次请求因为页面或网络重复提交：只处理一次。
- 添加成功提示中可以点击“撤销”。撤销会新增一条反向流水，不会删除历史记录。

默认数量和仓位可在“系统设置”中修改。
