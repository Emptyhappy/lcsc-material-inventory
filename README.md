# 立创商城物料管理系统

一个运行在本机的电子元器件库存系统。浏览器扩展可以在立创商城商品详情页一键读取商品参数和分类，并按默认数量 `1`、默认仓位直接入库；其他来源的物料可以在系统中手动添加。

## 已实现功能

- 立创商品页一键添加，无需手动填写型号、封装和参数
- 自动读取 C 编号、制造商型号、品牌、封装、规格参数、图片、数据手册、价格和分类
- 重复 C 编号不会重复建档，再次点击会继续入库 `+1`
- 请求防重和刚添加流水撤销
- 立创完整分类树同步、父子分类筛选和分类库存统计
- 手动添加非立创物料
- 默认数量、默认仓位和自定义仓位
- 入库、出库、库存调整及完整流水
- 名称、型号、内部编号和 C 编号搜索
- 低库存筛选、CSV 导出和 SQLite 单文件备份
- 不依赖第三方 Python 包

## 启动物料系统

双击 [start.bat](start.bat)，浏览器会自动打开：

```text
http://127.0.0.1:8765
```

第一次启动会在后台同步立创公开分类。如果当时网络不可用，可以进入“系统设置”，点击“同步立创分类”重试。

数据库默认保存在：

```text
data/materials.db
```

备份时先关闭启动窗口，再复制这个数据库文件。

也可以在命令行启动：

```powershell
python run.py
```

## 安装 Edge/Chrome 扩展

### Edge

1. 打开 `edge://extensions/`。
2. 打开左侧“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目中的 `extension` 文件夹。

### Chrome

1. 打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目中的 `extension` 文件夹。

### 首次连接

1. 保持物料系统正在运行。
2. 打开物料系统的“系统设置”。
3. 在“浏览器扩展连接”中复制连接密钥。
4. 打开扩展的“选项/扩展选项”。
5. 粘贴密钥，点击“保存并测试连接”。

连接成功后，打开形如 `https://item.szlcsc.com/100411.html` 的立创商品详情页，右侧会出现“加入我的物料库”按钮。

## 一键添加规则

- 第一次点击：创建物料档案，并在默认仓位入库默认数量。
- 同一个 C 编号再次点击：更新商品信息，不重复建档，继续入库默认数量。
- 同一次请求因为页面或网络重复提交：只处理一次。
- 添加成功提示中可以点击“撤销”。撤销会新增一条反向流水，不会删除历史记录。

默认数量和仓位可在“系统设置”中修改。
